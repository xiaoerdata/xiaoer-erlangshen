# /analyze 命令

## 用途
综合分析命令，自动识别查询意图并调用相应的专业Agent

## 用法
```
/analyze <查询内容>
```

## 示例
```
/analyze A股当前走势
/analyze 茅台投资价值
/analyze 黄金避险情绪
/analyze 当前宏观经济形势
```

## 行为
- 自动识别查询意图 (宏观/股票/多资产)
- 调用对应的专业Agent进行分析
- 返回结构化的分析报告

## 示例输出
```
## 核心观点
(1-2句话概括)

## 宏观环境
...

## 市场现状
...

## 风险提示
...

## 投资建议
...
```
