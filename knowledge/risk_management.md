# 风险管理

## 风险类型

### 市场风险
- **定义**: 市场整体下跌导致亏损
- **衡量**: Beta, VaR
- **缓释**: 分散化, 对冲

### 信用风险
- **定义**: 交易对手违约
- **衡量**: 信用利差, 违约概率
- **缓释**: 评估对手, 抵押品

### 流动性风险
- **定义**: 无法及时买入/卖出
- **衡量**: 买卖价差, 日成交量
- **缓释**: 避免小市值, 限价单

### 操作风险
- **定义**: 系统故障, 人为错误
- **衡量**: 事件统计
- **缓释**: 风控系统, 复核机制

## 投资组合风险指标

### 波动率
```python
# 日波动率
daily_returns = prices.pct_change()
volatility = daily_returns.std()

# 年化波动率
annual_vol = volatility * sqrt(252)
```

### Beta
```python
# 组合Beta vs 市场
portfolio_returns = ...
market_returns = ...
beta = portfolio_returns.cov(market_returns) / market_returns.var()
```

### VaR (Value at Risk)
| 类型 | 描述 | 置信度 |
|------|------|--------|
| 历史VaR | 历史数据分位数 | 95%-99% |
| 参数VaR | 正态分布假设 | 95%-99% |
| Monte Carlo VaR | 模拟方法 | 95%-99% |

### 最大回撤
```python
# 最大回撤计算
cummax = prices.cummax()
drawdown = (prices - cummax) / cummax
max_drawdown = drawdown.min()
```

## 对冲策略

### 股票对冲
- **方法**: 买入看跌期权 / 融券卖出
- **成本**: 期权费 / 融券利息
- **适用**: 下跌保护

### 期货对冲
- **方法**: 卖出指数期货
- **成本**: 基差风险
- **适用**: 组合Beta管理

### 期权策略
| 策略 | 构建 | 目的 |
|------|------|------|
| Protective Put | 持有股票 + 买入看跌 | 下跌保护 |
| Covered Call | 持有股票 + 卖出看涨 | 增强收益 |
| Collar | 持有股票 + 买看跌 + 卖看涨 | 成本最小化 |

## 风控流程

### 交易前
1. 风险预算检查
2. 仓位限制检查

4. 集中度检查

### 交易中
1. 实时监控仓位
2. 触发止损检查
3. 风险限额监控

### 交易后
1. 业绩归因分析
2. 风险分析复盘
3. 模型回测验证

## 止损策略

### 固定止损
```
止损价格 = 买入价格 × (1 - 止损比例)
例: 买入10元, 止损5% → 止损9.5元
```

### 跟踪止损
```
跟踪止损 = 最高价 × (1 - 跟踪比例)
例: 最高12元, 跟踪10% → 止损10.8元
```

### 时间止损
- 持仓超过N天无盈利 → 卖出
- 建议: 5-20个交易日
