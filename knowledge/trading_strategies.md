# 交易策略库

## 趋势跟踪策略

### 均线策略

#### 双均线策略
- **参数**: MA20 + MA60
- **信号**: 
  - 金叉 (MA20上穿MA60) → 买入
  - 死叉 (MA20下穿MA60) → 卖出
- **周期**: 日线为主

#### 多均线策略
- **参数**: MA20, MA60, MA120, MA200
- **信号**: 价格站上所有均线且均线多头排列 → 买入

### MACD策略
- **参数**: 12, 26, 9
- **信号**:
  - MACD线金叉Signal线 → 买入
  - MACD线死叉Signal线 → 卖出
  - MACD柱由负转正 → 买入

### 布林带策略
- **参数**: 20日均线, ±2标准差
- **信号**:
  - 价格触及下轨 → 买入
  - 价格触及上轨 → 卖出
  - 布林带收口 → 突破方向确认

## 均值回归策略

### RSI策略
- **参数**: 14日RSI
- **信号**:
  - RSI<30 → 超卖, 买入信号
  - RSI>70 → 超买, 卖出信号
  - RSI<20 → 极度超卖

### KD指标策略
- **参数**: 9, 3, 3
- **信号**:
  - K值<20且金叉D值 → 买入
  - K值>80且死叉D值 → 卖出

### 布林带均值回归
- **参数**: 20日均线, ±2标准差
- **信号**:
  - 价格触及下轨 → 买入
  - 价格触及上轨 → 卖出
  - 中轨作为止损参考

## 动量策略

### 动量因子
- **定义**: 过去N日收益率
- **信号**: 买入动量最强, 卖出动量最弱
- **周期**: 1-12个月

### 相对强弱策略
- **计算**: 个股收益 - 市场收益
- **信号**: 相对强弱高于阈值 → 买入

## 套利策略

### 跨期套利
- **标的**: 期货不同到期合约
- **信号**: 价差偏离历史均值 → 买入低, 卖出高

### 跨市场套利
- **标的**: 同一资产不同市场
- **标的**: A/H股, ETF/成分股

### 期现套利
- **标的**: 期货 vs 现货指数
- **信号**: 基差 > 持有成本 → 买入期货

## 事件驱动策略

### 美股财报交易
- **方法**:
  - 财报前: 隐含波动率高, 卖出期权
  - 财报后: 方向确定后买入
- **风险**: 财报意外

### 宏观事件策略
- **事件**: 央行会议, GDP发布, 非农
- **方法**: 事件前减仓, 事件后顺势

## 风控原则

### 仓位管理
| 方法 | 描述 | 适用场景 |
|------|------|----------|
| 固定仓位 | 每笔固定金额 | 趋势跟踪 |
| 等权仓位 | 各标的等权重 | 多策略 |
| 风险平价 | 按波动率倒数分配 | 组合投资 |
| 凯利公式 | f = (bp-q)/b | 优势明显时 |

### 止损方法
| 方法 | 描述 | 参数 |
|------|------|------|
| 固定止损 | 价格跌破固定比例 | 5%-10% |
| 跟踪止损 | 最高点回落固定比例 | 5%-20% |
| 时间止损 | 持仓超过N天 | 5-20日 |
| 波动率止损 | ATR倍数止损 | 2-3倍ATR |

### 风险指标
- **最大回撤**: 组合历史最大亏损
- **夏普比率**: (收益-无风险)/波动率
- **卡玛比率**: 年化收益/最大回撤
- **胜率**: 盈利交易占比
- **盈亏比**: 平均盈利/平均亏损
