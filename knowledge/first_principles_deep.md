## 一、完整认知体系

### 信息维度
| 要素 | 衡量指标 | 典型突破 |
|------|---------|---------|
| 计算力 | 算力/能耗、晶体管密度 | GPU集群、摩尔定律 |
| 传输效率 | 延迟、带宽、成本 | 光纤→5G→6G |
| 智能水平 | 认知、推理、创造力 | AI大模型、AGI |

### 能量维度
| 要素 | 衡量指标 | 典型突破 |
|------|---------|---------|
| 能量密度 | kWh/kg、kWh/m³ | 电池技术、固态电池 |
| 转化效率 | %、损耗率 | 光伏、风电、电机 |
| 获取便利性 | 成本/度、安装难度 | 分布式能源、绿氢 |

### 历史案例分析
| 时代 | 信息突破 | 能量突破 | 结果 |
|------|---------|---------|------|
| 工业革命1.0 | 机械计算 | 煤炭 | 机器替代人工 |
| 电气时代 | 电报/电话 | 电力传输 | 全球化起步 |
| 信息革命 | 计算机/互联网 | 石油驱动 | 经济全球化 |
| **当前** | AI/大数据 | **新能源** | 生产力跃升 |

## 二、技术成熟度判断框架

```
感知期 → 膨胀期 → 低谷期 → 复苏期 → 成熟期
(萌芽)   (狂热)   (淘汰)   (稳步)   (收割)

判断方法：
1. 是否已过"PPT阶段"？
2. 是否有真实商业化收入？
3. 竞争格局是否开始分化？
4. 估值是否合理？

当前典型：
- AI大模型：膨胀期末 → 即将进入低谷
- 新能源车：复苏期 → 快速走向成熟
- 固态电池：感知期 → 膨胀期
- 元宇宙：低谷期（2022-2024）
```

## 三、投资逻辑推导

### 单维度突破 → 局部优化
```
信息突破 → 效率提升 → 软件/互联网受益
能量突破 → 成本下降 → 能源/制造业受益
```

### 双维度突破 → 产业革命
```
信息+能量同时突破 → 新物种出现
例：智能手机 = 信息(触控/移动计算) + 能量(锂电池)
```

### 产业链价值分布
```
          上游          中游           下游
        (资源/技术)   (制造/集成)    (品牌/服务)
        
能源革命：矿产资源 → 电池厂 → 整车厂 → 用户
信息革命：芯片/算法 → 平台 → 应用 → 用户
```

## 四、分析模板

遇到新变革时，按此顺序分析：

```
1. 【定性】这是什么？
   - 信息突破？能量突破？双突破？
   
2. 【定位】处于哪个阶段？
   - 感知→膨胀→低谷→复苏→成熟
   
3. 【找钱】价值链在哪里？
   - 谁掌握核心资源/技术？
   - 谁最先把技术变成产品？
   - 谁最终赚到钱？
   
4. 【时机】现在适合投资吗？
   - 早：风险高，赔率高
   - 中：确定性高，成长空间清晰
   - 晚：竞争红海，格局已定
```

## 五、常见错误清单

| 错误 | 正确 |
|------|------|
| 把"热门"当成"革命" | 先问：信息or能量突破？ |
| 忽视双维度效应 | 新能源车=能源+信息双革命 |
| 技术乐观主义 | 很多技术在低谷期死掉 |
| 忽视产业链规律 | 上游吃肉，下游喝汤 |
| 把周期当趋势 | 先分清周期波动和长期趋势 |
