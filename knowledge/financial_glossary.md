# 金融术语表

## 投资术语

### A-H
| 术语 | 英文 | 解释 |
|------|------|------|
| 夏普比率 | Sharpe Ratio | 风险调整后收益, (收益-无风险)/波动率 |
| 阿尔法 | Alpha | 超额收益, 组合收益-基准收益 |
| 贝塔 | Beta | 市场敏感度, 组合与市场相关性 |
| 最大回撤 | Max Drawdown | 从高点最大跌幅 |
| 卡尔玛比率 | Calmar Ratio | 年化收益/最大回撤 |
| 索提诺比率 | Sortino Ratio | 风险调整后收益, 只考虑下行波动 |
| 波动率 | Volatility | 收益率标准差, 年化 |
| 收益率为正 | Win Rate | 盈利交易占比 |
| 盈亏比 | Profit Factor | 平均盈利/平均亏损 |
| 预期收益 | Expected Return | 各情景概率加权收益 |
| 在险价值 | VaR | 一定置信度最大损失 |
| 条件VaR | CVaR/ES | 超VaR的平均损失 |
| 久期 | Duration | 债券价格对利率敏感度 |
| DV01 | Dollar Value of 1bp | 收益率变化1bp的美元影响 |
| 凸性 | Convexity | 久期对利率变化的二阶导 |
| 信用利差 | Credit Spread | 企业债-国债收益率差 |
| 基差 | Basis | 期货-现货价差 |
| 升水 | Contango | 期货高于现货 |
| 贴水 | Backwardation | 期货低于现货 |
| 展期收益 | Roll Yield | 展期产生的收益 |
