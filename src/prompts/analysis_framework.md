# 分析框架 (Analysis Framework)

## 1. 宏观分析框架

### 1.1 经济周期
```
领先指标: PMI, 消费者信心, 库存变化
同步指标: GDP, 工业增加值, 就业
滞后指标: CPI, PPI, 利率
```

### 1.2 货币政策框架
```
目标: 价格稳定, 充分就业, 金融稳定
工具: 利率, 存款准备金, 公开市场操作, QE
传导: 利率 → 信用 → 投资/消费 → 经济
```

### 1.3 政策评估矩阵
| 政策类型 | 宽松 | 中性 | 紧缩 |
|---------|------|------|------|
| 财政政策 | 扩张性 | 中性 | 收缩性 |
| 货币政策 | 宽松 | 中性 | 紧缩 |
| 监管政策 | 放松 | 中性 | 收紧 |

## 2. 股票分析框架

### 2.1 盈利分析
```
收入端:
- 营收增长率 (YoY, QoQ)
- 市场份额变化
- 产品/服务定价能力

成本端:
- 毛利率趋势
- 费用率控制
- 规模效应

最终:
- EPS增长
- ROE趋势
- 现金流质量
```

### 2.2 估值分析
```
绝对估值:
- DCF折现率
- 永续增长率假设

相对估值:
- PE/PB/PS分位数
- 与行业平均比较
- 与历史区间比较

情景分析:
- 乐观/基准/悲观
```

### 2.3 质量因子
```
财务质量:
- 资产负债率
- 经营现金流/净利润
- 应收账款周转

竞争壁垒:
- 护城河类型
- 行业地位
- 品牌溢价

管理层:
- 治理结构
- 激励机制
- 历史记录
```

## 3. 资产配置框架

### 3.1 风险预算
```
股债比例:
- 保守: 30/70
- 均衡: 60/40
- 积极: 80/20

区域配置:
- 本土偏好
- 新兴vs发达
- 行业敞口

风格配置:
- 成长vs价值
- 大盘vs小盘
```

### 3.2 再平衡策略
```
阈值再平衡:
- 股债偏离超过5%时触发

时间再平衡:
- 季度/年度定期检视

动态再平衡:
- 基于风险平价
- 基于相对价值
```

## 4. 风控框架

### 4.1 风险识别
```
市场风险:
- 系统性风险暴露
- 相关性风险

信用风险:
- 交易对手信用
- 发行人信用

流动性风险:
- 持仓流动性
- 赎回压力

操作风险:
- 执行风险
- 模型风险
```

### 4.2 风险度量
```
VaR (Value at Risk):
- 95%/99%置信度
- 1天/10天持有期

回撤:
- 最大回撤
- 回撤修复时间

波动率:
- 历史波动率
- 隐含波动率
```

## 5. 决策流程

```
1. 信息收集
   └── 数据采集 → 清洗 → 验证

2. 分析推理
   └── 宏观 → 行业 → 个券

3. 组合构建
   └── 战略配置 → 战术调整 → 个券选择

4. 执行监控
   └── 下单 → 结算 → 跟踪

5. 复盘反思
   └── 归因 → 总结 → 迭代
```
